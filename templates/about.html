Credit Card Fraud Detection

About This Project

This Credit Card Fraud Detection System uses Machine Learning to identify whether a credit card transaction is genuine or fraudulent.

Project Features

  • Predict single transactions instantly.
  • Upload CSV files for batch prediction.
  • Fast and accurate fraud detection.
  • User-friendly responsive interface.
  • Machine Learning based prediction.

Technologies Used

Technology Purpose
Python Backend Programming
Flask Web Framework
HTML Frontend Structure
CSS Styling
Bootstrap Responsive Design
Pandas Data Processing
Scikit-Learn Machine Learning

Objective

The objective of this project is to detect fraudulent credit card transactions quickly, helping financial institutions reduce financial losses and improve customer security using Machine Learning techniques.
